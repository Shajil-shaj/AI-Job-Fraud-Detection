# AI Job Fraud Detection System

This project detects fake and genuine job postings using Machine Learning and NLP.

## Tech Stack
- Python
- Scikit-learn
- TF-IDF
- Naive Bayes
- Streamlit

## Run project
pip install -r requirements.txt
streamlit run app.py

## Note
Dataset not uploaded due to file size. Run train_model.py to generate model files.
